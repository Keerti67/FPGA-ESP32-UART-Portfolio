02 / ENGINEERING NEED

Problem and Need

02
PROBLEM DEFINITION

Reliable bidirectional communication across two different platforms

Communication between an FPGA and a microcontroller requires compatible serial settings, accurate timing and correct interpretation of data frames. Implementing both transmission and reception introduces separate logic paths and synchronization requirements.

ENGINEERING NEED
  • Connect programmable logic with an embedded controller.
  • Demonstrate UART transmission and reception.
  • Verify baud timing and frame structure.
  • Evaluate integration through simulation and hardware tests.

06 / ENGINEERING DESIGN

Design and Calculations

06
UART BIT PERIODTbit = 1 / Baud rate

At a 9600 bit/s baseline, one bit period is approximately 104.17 μs.

FPGA CLOCKS PER BITN = fclk / Baud rate

For a 100 MHz clock and 9600 baud, N ≈ 10,416.67. The implementation must handle integer division and timing error deliberately.

These are reference calculations based on the baseline values shown on the overview. Confirm the actual clock and baud-rate settings in your RTL and ESP32 code.
